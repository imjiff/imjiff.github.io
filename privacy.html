Privacy Policy

Last updated: 27 September 2026

About this tool

Compliance Files Uploader is a private tool used only by the owner of The Compliance Files YouTube channel. It uses YouTube API Services to upload videos, titles, descriptions, tags and comments to the owner's own channel.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

What data is used

The tool does not collect, store or share data from any YouTube users or viewers. The only data it stores is the ID and link of each video it uploads, and an access token for the channel owner's own account, held in encrypted form.

Data deletion and revoking access

The channel owner can revoke this tool's access at any time from the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the stored token is deleted and no further data is accessed. Any stored video IDs can be deleted on request within 7 days by emailing the address below.
